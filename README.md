REST Countries API Integration with Python
A Python application that retrieves country information from a REST API, processes the returned JSON data, and displays clean, structured information.
## Features
- Search for country information using a country name
- Retrieve data from a REST API
- Process JSON responses
- Extract relevant country information
- Handle API and request errors
- Handle missing data safely
- Display formatted country information in the terminal
## Technologies Used

- Python
- Requests
- REST API
- JSON
- URL encoding

## Project Structure

How It Works
The application takes a country name from the user and sends a request to a REST API.
The returned JSON data is processed to extract relevant information such as:
Country name
Region
Capital
Population
Currency
Languages
The extracted information is then transformed into a clean structure and displayed in the terminal.

Example Output
COUNTRY INFORMATION

Country: Canada
Region: Americas
First Language: English
Capital: Ottawa
Population: 41798407
Currency: Canadian dollar
Languages: English, French
